## 1. Executive Summary

Phase 2 focused on constructing a synthetic noisy/clean speech corpus (`data/mixtures/`) and dataset manifest (`data/manifest.csv`) for benchmarking classical DSP baselines and AI/ML noise suppression models. 

The dataset contains **300 synthetic mixtures** generated at a uniform **48,000 Hz** (48 kHz) sample rate, spanning 3 primary noise categories, 7 subtypes, and 5 Signal-to-Noise Ratio (SNR) levels (`-5 dB, 0 dB, +5 dB, +10 dB, +15 dB`). Post-mixing verification confirmed a **0.0000 dB mean SNR deviation** and **100% manifest-to-disk file parity**.

## 3. Technical Implementation & Software Infrastructure

### 3.1 Dataset Synthesis Pipeline (`data/mix_dataset.py`)
- **Sample Rate Standard (Rule 14):** All clean and noise clips are dynamically resampled to 48 kHz before mixing using DeepFilterNet's native sinc interpolation kernel.
- **Seeded Reproducibility:** Accepts `--seed` parameter generating deterministic clean/noise clip pairings and temporal offsets for 100% reproducible dataset builds.
- **Energy Scaling Math:**
  $$P_s = \frac{1}{N}\sum s[n]^2, \quad P_d = \frac{1}{N}\sum d[n]^2, \quad a = \sqrt{\frac{P_s}{P_d \cdot 10^{\text{SNR}_{\text{dB}}/10}}}$$
  $$\text{Mixed}[n] = s[n] + a \cdot d[n]$$
- **Peak Normalization:** Prevents digital clipping by scaling mixed signals if peak amplitude exceeds 0.95.

### 3.2 Crowd Babble Synthesizer (`scripts/generate_babble_noise.py`)
- Overlaps 6 random clean speech utterances at random temporal shifts and gain variations ($\pm 3 \text{ dB}$) to generate realistic background crowd babble.

### 3.3 Dataset Manifest Structure (`data/manifest.csv`)
Contains 300 rows with 10 fields:
`clean_id, noise_id, category, snr_db, seed, output_path, subtype, duration_sec, achieved_snr_db, snr_dev_db`.
